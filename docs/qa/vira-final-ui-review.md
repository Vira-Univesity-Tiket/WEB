## نسخه و معیار نتیجه

مبنای بازبینی commit `b26fd3c894da9e65461702689103f970c40237a6` روی شاخهٔ موجود `feat/vira-driver-ui-redesign` در مخزن `Vira-Univesity-Tiket/WEB` است. شروع کار با working tree پاک بود؛ پس از fetch، upstream جلوتر از HEAD نبود. ادغام با main یا انتشار production در این مأموریت انجام نمی‌شود.

نتیجهٔ نهایی: **۲۸ حالت اجرا و بررسی شد؛ ۲۷ مرجع نهایی قابل تطبیق بود؛ ۲۷ PASS، صفر FAIL و یک BLOCKED (D05)**. بخش دانشجو ۱۸ PASS و بخش راننده ۹ PASS و یک BLOCKED دارد. برای هر حالت، تصویر نسخهٔ اصلاح‌شده دوباره کنار مرجع باز شد؛ نماهای تکمیلی اسکرول و مرور چهار عرض دیگر نیز باز شدند.

PASS یعنی ساختار، عناصر، سبک مشترک و تعامل همان حالت با مرجع موجود و دادهٔ معتبر آزمایش بررسی شده است، با تفاوت‌های مقیاس و قرارداد ثبت‌شده در این گزارش؛ به معنی برابری پیکسلی یا تأیید سخت‌افزار/درگاه عملیاتی نیست. FAIL برای نقص حل‌نشده و BLOCKED برای نبود مدرک یا دسترسی لازم است. معیار تطبیق نهایی تصویر D05 هنوز تکمیل نشده است.

هیچ فایل backend، دیتابیس، migration، API client، قرارداد درخواست/پاسخ، احراز هویت، نقش یا منطق قیمت/کیف پول/اعتبار بلیت تغییر نکرده است. عملیات مؤثر فقط روی دیتابیس‌های موقت loopback با fixture موجود انجام شده‌اند.

## جریان مشترک و بررسی تکمیلی

آزمون موجود `app.spec.ts` ورود/رزرو کاربر، تولید QR واقعی، خواندن آن با jsQR از stream نرم‌افزاری، ثبت توسط رانندهٔ مجاز، رد QR نامعتبر، ثبت بلیت دوم در همان stream و رد ثبت مجدد را اجرا کرد. کنترل موجودی پیش/پس از دو خرید، ثابت‌ماندن آن پس از اسکن و تلاش تکراری، شمار سابقه و `boardedAt/status` همان شناسه‌ها اضافه شد. موفقیت ثبت با پاسخ mock تأیید نشد.

**نتیجهٔ جریان مشترک: PASS در محیط تست واقعی API.** دو بلیت با شناسه‌های fixture `1` و `2` صادر شدند. موجودی ۱۰۰٬۰۰۰ تومان پس از دو خرید ۵٬۰۰۰ تومانی به ۹۰٬۰۰۰ رسید؛ بعد از هر دو اسکن و تلاش تکراری همچنان ۹۰٬۰۰۰ ماند. سرور دو سابقه برای همان شناسه‌ها و `boardedAt` معتبر برگرداند؛ وضعیت API مطابق قرارداد موجود `expired` است و رابط سفر انجام‌شده/آرشیو را نشان داد. درخواست ثبت تکراری HTTP 409 داشت. سه کلیک خرید فقط یک درخواست رزرو و stream پیوسته حداکثر یک درخواست اسکن همزمان داشت. ثبت نظر سفر پس از سوارشدن نیز موفق بود.

شاهدها در `final/shared-flow/`: `shared-flow-result.json` (بدون token/payload QR)، `ticket-issued-mobile.png`، `shared-flow-driver-stats.png`، `shared-flow-driver-history.png` و `shared-flow-student-archive.png`. داده و QR مربوط به دیتابیس موقت حذف‌شدهٔ تست‌اند و مسافر واقعی نیستند. اسکن سخت‌افزاری دوربین واقعی همچنان تأییدنشده است.

آزمون paste، رویداد `inputType=insertFromPaste` با `٠٠٣٧` را به کنترل واقعی می‌رساند و رشتهٔ ارسالی `0037` را بررسی می‌کند؛ clipboard سیستم خوانده/عوض نمی‌شود. این شبیه‌سازی ورودی paste است، نه تست منوی clipboard دستگاه فیزیکی.

حالت‌های شبکه/منبع خالی، کمبود موجودی، ظرفیت پر، نشست/مجوز، پاسخ دیررس، اصلاح ثبت‌نام ردشده، مدرک نامعتبر، حفظ فرم و نتیجهٔ نامشخص با آزمون‌های موجود بررسی می‌شوند. نمای کوتاه `360×520` نیز پوشیده‌نشدن کد زیر ناوبری را می‌سنجد؛ جای صفحه‌کلید واقعی گوشی نیست.

## اجرای بررسی‌ها

```powershell
npm run typecheck
npm run lint
npm test
node --env-file=.env --test tests/api.integration.test.mjs tests/catalog.integration.test.mjs
npm run build
$env:VIRA_BROWSER_PREVIEW = 'true'
node --env-file=.env node_modules/@playwright/test/cli.js test
npm audit --json
npm --prefix backend audit --omit=dev --json
git diff --check
```

| بررسی اجراشده | نتیجهٔ واقعی |
| --- | --- |
| `typecheck` و `lint` | موفق؛ پس از آخرین تغییر آزمون نیز دوباره اجرا شدند |
| `npm test` | ۲۵ آزمون موفق، صفر شکست |
| دو مجموعهٔ integration با DB موقت | ۲۱ آزمون موفق، صفر شکست |
| `npm run build` | موفق؛ Vite، بدون تغییر وابستگی |
| مجموعهٔ کامل مرورگر روی build نهایی | ۲۶ آزمون موفق در ۸٫۶ دقیقه، صفر شکست |
| کنترل دسترس‌پذیری خودکار در تست‌های ۳۹۰ | صفر مورد serious/critical در قواعد اجراشدهٔ axe؛ جای ممیزی کامل انسانی نیست |
| audit ریشه و backend production | صفر آسیب‌پذیری گزارش‌شده در هر دو؛ وابستگی جدید اضافه نشد |
| `git diff --check` | موفق |
| گالری محلی شواهد | ۲۸ انتخاب و هر ۱۴۰ تصویر اصلی در مرورگر بارگذاری شد؛ صفر خطای script، هشدار D05 حاضر |

پس از افزودن عکس جداگانهٔ آمار/سابقه و کنترل دو ردیف واقعی، سناریوی مشترک به‌تنهایی دوباره اجرا شد: **یک آزمون موفق، صفر شکست، ۱٫۲ دقیقه**. این تغییر فقط آزمون/شاهد را تکمیل می‌کند و سورس runtime همان نسخهٔ مجموعهٔ کامل است. نتیجهٔ اجرای تکمیلی در `browser-shared-final.log` نگهداری می‌شود.

اجرای محلی: `npm --prefix backend run dev` و در ترمینال دیگر `npm run dev -- --port 3002 --strictPort` با محیط معتبر فعلی؛ مسیرهای `http://127.0.0.1:3002/` و `/driver`. آزمون از `.env` و `VIRA_TEST_DB_URL` مجاز محلی استفاده می‌کند؛ فایل محیط یا credential در Git/گزارش نیست. سرورهای بررسی مرورگر روی 3017/3018 با APIهای 5017/5018 و دیتابیس‌های مستقل اجرا و پس از آزمون متوقف شدند.

## بازبینی امنیت و رگرسیون

diff سورس، آزمون‌ها و trust boundary نزدیک بررسی شد: تغییرات محصول محدود به CSS، جانمایی، متن نمایشی، آیکن و مسیر ثابت تصویر هستند. ورودی HTML خام، مقصد redirect یا endpoint جدید، ذخیرهٔ credential، فراخوانی مالی تازه و تغییر مجوز اضافه نشد. رمز/مدرک به storage منتقل نشد و دادهٔ ساختگی وارد رفتار محصول نشد. حالت نتیجهٔ نامشخص، عدم تکرار خودکار ثبت، حفاظت نشست و پاسخ دیررس در آزمون‌های موجود موفق‌اند. هیچ نقص امنیتی تازهٔ مادی در محدودهٔ این diff مشاهده نشد؛ این نتیجه ممیزی کامل backend نیست.

فهرست فایل‌های staged و diff پیش از commit بررسی شد؛ خروجی build، cache، screenshot، DB، فایل محیط، trace و log در commit نیستند. گزارش دستی و دارایی‌های مستقل جزو تحویل سورس هستند.

## محدودیت‌ها و انتشار

- مرجع نهایی D05 موجود نیست؛ وضعیت بصری BLOCKED حتی با صحت کنترل‌های صریح باقی می‌ماند.
- دوربین فیزیکی، نبود سخت‌افزار واقعی، Safari/Firefox و صفحه‌کلید واقعی گوشی تأیید نمی‌شوند. رد مجوز، stream نرم‌افزاری و توقف دیررس دوربین آزمون دارند.
- پرداخت بیرونی یا اثر مالی production انجام نمی‌شود. خطای آغاز درگاه و callbackهای محیط تست، تأیید درگاه عملیاتی نیستند.
- نسبت رستر، فونت، تعداد ردیف و دادهٔ پویا متفاوت‌اند؛ خوانایی، کنترل لمسی و اسکرول حفظ شده و برای تقلید رستر داده ثابت نشده است.
- مقیاس مشترک Vazirmatn، ورودی‌های ۵۴/۵۶ پیکسلی و QR خوانا باعث می‌شوند فرم‌های U03، U12، U14، D02–D04 و بلیت U17 در گوشی کوتاه به اسکرول بیشتری از بعضی رسترها نیاز داشته باشند. نماهای تکمیلی دسترسی به اقدام آخر را نشان می‌دهند. اندازهٔ تصویر و محل خط تزئینی پایین نیز دقیقاً پیکسل‌به‌پیکسل برابر نیست.
- در U04 متن نام بلند خدمت ممکن است دوخطی شود؛ در D09 کنترل زمان native و compact حدود ۱۶۰ پیکسل قبلی حفظ شده و مثل رستر تمام‌عرض نیست. محدودیت ضمیمهٔ U12 و راهنمای مدرک D03 عمداً قرارداد واقعی سرور را نشان می‌دهند. لوگوی معتبر پروژه جای نشان متفاوت تولیدشدهٔ بعضی مراجع راننده حفظ شده است.
- شواهد و ZIP مرور خارج از Git هستند. تنها سورس، دارایی مستقل، آزمون هدفمند و این گزارش به شاخهٔ کاری push می‌شوند. SHA نهایی و تطبیق remote در تحویل و manifest محلی ثبت می‌شوند؛ push، انتشار production نیست.
